# ThemeCV AI - Professional Career Engine

ThemeCV AI is a high-precision career management system that architecturally synthesizes your professional identity using AI.

## 🚀 Getting Started

### 1. Prerequisites
- **Node.js**: Version 18.0.0 or higher
- **NPM**: Latest version

### 2. Exporting Code
If you are viewing this in Google AI Studio:
1. Go to the **Settings** menu.
2. Select **Export to GitHub** or **Download as ZIP**.

### 3. Local Installation
Once you have the code locally, navigate to the project directory and run:
```bash
npm install
```

### 4. Running the Development Server
To start the application in development mode:
```bash
npm run dev
```
The application will be available at `http://localhost:3000`.

### 5. Environment Variables
You will need a **SerpAPI Key** to enable the Market Search features.
1. Create a `.env` file in the root directory.
2. Add your key: `SERPAPI_KEY=your_key_here`

## 🛠 Tech Stack
- **Frontend**: React 18, Vite, Tailwind CSS v4
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **AI Integration**: Gemini API (via server proxy)
- **Search**: SerpAPI (for real-time job lead scanning)
